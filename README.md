# AirHUST 2026 梯队培训

本仓库按五个关卡整理培训材料。目前提供第二关的讲义与 template 包，并收录点云、视觉方向的第三关练习和第四关相关材料。

## 关卡目录

| 关卡 | 内容 | 当前状态 |
| --- | --- | --- |
| [第 1 关](1关/) | 环境搭建与仿真入门 | 待补充 |
| [第 2 关](2关/README.md) | 阅读 template、理解控制流并实现绕圈 | 已提供讲义与任务 |
| [第 3 关](3关/README.md) | 分方向补齐关键代码 | 已收录点云、视觉材料 |
| [第 4 关](4关/README.md) | 分方向完成小场景任务 | 已提供视觉仿真与点云在线练习入口 |
| [第 5 关](5关/) | 组队完成多方向融合项目 | 待补充 |

## 从第二关开始

1. 阅读 [template 入门讲义](2关/第二关-template入门.md)。
2. 完成 [练习与绕圈任务](2关/第二关-练习与绕圈任务.md)。
3. 按讲义使用 [template 下载包](2关/template.zip)，解压后放入第一关 ROS 工作空间的 src 中编译运行。

本仓库根目录用于整理培训材料；第二关源码位于 [2关/src/template](2关/src/template/)。编译时使用讲义指定的 ROS 工作空间。

## 分方向继续

- [点云方向](3关/点云/接入说明.md)：点云读写、发布、滤波、邻域搜索、聚类和在线综合练习。
- [视觉方向](3关/视觉/接入说明.md)：颜色、二维码、AprilTag、OCR、YOLO，以及配套仿真场景。
- [第四关入口](4关/README.md)：进入各方向的小场景任务。

两份方向材料均以普通文件收录，首次克隆无需初始化子模块。各方向目录保留原工作空间结构；请按接入说明复制到个人目录后练习，不要把整个培训仓库作为一个 catkin 工作空间编译。来源与收录版本见 [材料来源](材料来源.md)。
