# 视觉方向接入说明

本目录收录 [dunantedage1/airhust_tutorial26_vision_lab](https://github.com/dunantedage1/airhust_tutorial26_vision_lab) 的完整材料，保留原作者的 [README](README.md)、两个板块的讲义、练习脚本、图片、权重及仿真场景。

## 准备个人副本

本目录同时包含第三关离线练习和第四关仿真包。为沿用原讲义的路径，请在第一关 Linux 环境中，将当前目录完整复制为 `~/airhust_tutorial26_vision_lab`。下面在本目录打开 Bash 后执行；目标已存在时会停止，避免覆盖以前的练习：

```bash
test ! -e "$HOME/airhust_tutorial26_vision_lab" || { echo "目标已存在，请先选择另一个个人副本目录"; exit 1; }
cp -a . "$HOME/airhust_tutorial26_vision_lab"
```

随后按 [板块三：函数原型与静态调用](<src/板块3 函数原型与静态调用/README.md>) 完成五项离线练习。Python 依赖单独见 `src/lab_vision_sim_task3/requirements.txt`；ROS 镜像提供基础环境，不代表所有视觉依赖已安装。

## 第四关的相机模型需要补齐

配套任务见 [板块四：仿真单元测试](<src/板块4 仿真单元测试/README.md>)。启动文件引用：

```text
$(find simulation)/models/iris_down_cam/model.sdf
```

目前对第一关原始 ISO 的只读检查只看到 `simulation/models/iris`，没有 `iris_down_cam`。这个方向仓库也没有提供该飞行器模型。因此，需要先在个人环境中补齐向下相机模型，并核对图像话题，再运行仿真任务。现有 `iris` 不能仅通过改目录名代替带相机的模型。

本次保留原作者的 launch 和源码，不凭推测补相机模型，也未启动仿真。已经核对收录文件完整性，第一关镜像中的编译、视觉依赖和飞行流程仍待云端验证。
