# 避障方向接入说明

本目录完整收录 [yan233966/airhust_tutorial26_collision_avoidance](https://github.com/yan233966/airhust_tutorial26_collision_avoidance) 的源码、配置、地图及讲义。

先阅读 [人工势场法与任务说明](collision_avoidance.md)，按照原题理解算法并补全代码；[原始 README](README.md) 则提供任务节点、参数、接口及已知问题的参考。本次接入不补写练习答案。

## 准备个人工作空间

本目录是独立的 catkin 工作空间，自带 `template` 和 `mission` 包。不要覆盖第二关的教学 template，也不要把两个版本合并到同一个工作空间。

在第一关的 Linux 环境中使用 Bash，在本目录打开终端，将完整目录复制到个人位置；目标已存在时停止，避免覆盖已有练习：

```bash
test ! -e "$HOME/airhust_tutorial26_collision_avoidance" || { echo "目标已存在，请先选择另一个个人副本目录"; exit 1; }
cp -a . "$HOME/airhust_tutorial26_collision_avoidance"
cd "$HOME/airhust_tutorial26_collision_avoidance"
source /opt/ros/noetic/setup.bash
```

然后按原题修复配置、补全算法并编译。`src/mission/CMakeLists.txt` 目前引用 `yolov8_ros_msgs` 和 `cloud_recognition`，但本方向工作空间未包含这两个包；需要核实第一关环境是否提供，以及当前源码实际需要哪些依赖。原 README 还列有编译与启动问题，不能把这份快照当成已经编译通过的示例。

## 第三关与第四关的对应关系

- 第三关：阅读原讲义 Stage 1，补全 Stage 2 对应的 `src/template/include/avoidance.h` 等练习代码。
- 第四关：按照 Stage 3 使用 `worlds/collision_1.world` 测试，再按照 Stage 4 使用 `worlds/collision_2.world` 调试与优化。

任务 launch 只启动控制节点，仿真、MAVROS、定位和 `/cloud_registered` 点云需要第一关环境提供。数据输入按原题是世界系 ENU 点云，不能只因话题名称相同就假设坐标系也一致。

依赖、算法和构建问题解决后，在不同终端分别加载第一关仿真环境和当前个人工作空间，再按原题启动仿真与 `roslaunch mission avoidance.launch`。现有 `sim.launch` 支持 `world` 参数，可在个人环境中核对使用地图的绝对路径，无需移动或覆盖第一关原始地图。
