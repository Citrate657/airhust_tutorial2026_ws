## 准备个人副本

本目录本身就是点云练习工作空间。为沿用原讲义的路径，请在第一关 Linux 环境中，将当前目录完整复制为 `~/airhust_tutorial26_pcl_ws`。下面在本目录打开 Bash 后执行；目标已存在时会停止，避免覆盖以前的练习：

```bash
test ! -e "$HOME/airhust_tutorial26_pcl_ws" || { echo "目标已存在，请先选择另一个个人副本目录"; exit 1; }
cp -a . "$HOME/airhust_tutorial26_pcl_ws"
cd "$HOME/airhust_tutorial26_pcl_ws"
source /opt/ros/noetic/setup.bash
catkin_make --pkg tutorial_pcl_basic
```

编译成功后，按照 [阶段三讲义](docs/index.md) 逐步练习。`run`、`data`、`out` 与 `src` 需要一起保留，不能只复制 ROS 包：CMake 会按工作空间根目录查找数据和输出路径。

本仓库通过 Git 保留 `run` 的可执行标记；如果经 ZIP 或其他工具复制后丢失权限，可使用 `bash ./run 1` 启动。参考答案在 `solutions` 内，原项目默认不编译；先在练习源码中独立补全 TODO。
