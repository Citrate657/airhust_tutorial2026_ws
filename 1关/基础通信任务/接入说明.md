# 第一关基础通信任务接入说明

本目录完整收录 [consefact/tutor_26_misson1](https://github.com/consefact/tutor_26_misson1) 的题目、学生源码、启动脚本与预编译后端。先读原作者的 [README](README.md)，本说明只补充收录后的目录与环境用法，不提供练习答案。

## 准备个人副本

在第一关的 Linux 环境中使用 Bash，在本目录打开终端，将整个目录复制为 `~/drone_ws`。目标已存在时停止，避免覆盖已有练习：

```bash
test ! -e "$HOME/drone_ws" || { echo "目标已存在，请先选择另一个个人副本目录"; exit 1; }
cp -a . "$HOME/drone_ws"
cd "$HOME/drone_ws"
source ./setup.sh
```

必须一起保留 `install`、`src`、`setup.sh` 和 `run_sim.sh`。这里的 `install` 是作者提供的后端，不要当作普通构建缓存删除；其中两个后端可执行文件经文件头检查为 Linux x86-64 ELF，与镜像架构对应，实际运行仍待验证。

`setup.sh` 会根据个人副本位置修正后端安装路径，并加载 ROS、后端及已有的 devel 环境，因此请在个人副本内执行。先按题目修复编译配置，再运行 `catkin_make`，成功后重新 `source ./setup.sh`。

## 启动关系

原题目录表写了“一键起 sim + sensor + 你的节点”，但当前版本 `mission.launch` 实际只启动 `flight_node`。应采用原题后面的双终端方式：

```bash
# 终端 1：启动简化模拟后端和传感器
cd "$HOME/drone_ws"
bash ./run_sim.sh
```

```bash
# 终端 2：加载环境后启动自己编译的节点
cd "$HOME/drone_ws"
source ./setup.sh
roslaunch drone_bringup mission.launch
```

本任务接口是 `/drone/state`、`/drone/setpoint` 和 `/drone/sensor/obstacle_distance`。这些与第二关的 MAVROS 接口不同，按各关题目理解和使用。
